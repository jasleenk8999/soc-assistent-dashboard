# AI SOC Assistant — Design Exploration

## Three directions considered

| Theme Name | Very Brief Intro | Probability |
| --- | --- | ---: |
| Signal Room | An editorial command-center interface with a graphite foundation, dense but calm data blocks, and restrained infrared status accents. It should feel like a serious analyst workspace rather than a sci-fi control panel. | 0.07 |
| Field Notes | A warm, paper-like security workbench that treats incidents as case files, using layered notes and technical annotations to make complexity feel understandable. | 0.03 |
| The Night Shift | A high-contrast, dark terminal-inspired monitoring surface that uses depth, pale mint telemetry, and alert red sparingly to create focused operational intensity. | 0.08 |

## Chosen direction: Signal Room

### Design Movement

**Editorial operations design** blended with the measured utility of modern observability tooling. The layout resembles a security briefing surface: strong hierarchy, meaningful status signals, and a composed data rhythm.

### Core Principles

1. **Calm under pressure:** Threat data is prioritised through space, scale, and colour rather than visual noise.
2. **Evidence before decoration:** Every texture, marker, divider, and chart reinforces the idea of live operational telemetry.
3. **Designed asymmetry:** The information canvas uses a permanent rail, a directional header, and varied card spans rather than a centered grid of identical panels.
4. **Actionable intelligence:** Prominent AI explanations turn raw detections into concise next steps.

### Color Philosophy

The baseline is deep graphite and smoked blue, establishing a focused, low-glare environment suitable for extended monitoring. **Signal Lime** is reserved for verified, healthy, and live states; a muted ember red flags urgency without flooding the surface. Soft fog tones provide readable contrast and keep the interface human.

### Layout Paradigm

An anchored **analyst rail** on the left acts as the navigation spine, while the main work area unfolds as a left-aligned operational canvas. A briefing header leads into a hierarchy of health snapshot, attack trend, investigation queue, and an AI narration panel. Cards differ in weight and span so that the page reads like a live briefing, not a generic widget gallery.

### Signature Elements

1. **Signal hairlines:** fine, low-contrast rules and tiny terminal-style labels establish a telemetry rhythm.
2. **Confidence contours:** red-to-amber risk halos and concise confidence metadata frame important findings.
3. **The AI Brief:** an oversized, type-led explanation module with an offset lime rule makes the assistant’s reasoning a visible product differentiator.

### Interaction Philosophy

Controls behave like analyst instruments: tabs switch their local view instantly, action buttons give a firm tactile press, and hover states reveal intent without interrupting scanning. Placeholder actions will clearly report that their feature is not connected in this frontend demonstration.

### Animation

Entrance motion is reserved for the page’s first render: panels rise 6px and settle with 30–60ms staggered delays, while the live status pulse is subtle and slow. Chart points and alert rows should never loop theatrically. All nonessential movement is disabled for reduced-motion preferences.

### Typography System

**Space Grotesk** provides disciplined, technical display hierarchy for headings, figures, and identifiers. **Manrope** handles long-form interface copy with open, relaxed readability. Small labels use tracked uppercase Space Grotesk; body copy stays uncondensed and highly legible.

### Brand Essence

**An AI-assisted security command surface for analysts who need defensible clarity, not more noise.**

Personality: **assured, lucid, vigilant**.

### Brand Voice

Voice is concise, evidence-led, and quietly decisive. Headlines read like an operational finding; calls to action make the next best action explicit.

> “Anomalous authentication activity is rising.”

> “Review the evidence trail.”

### Wordmark & Logo

The logo is a compact **split-shield radar aperture**: two offset planes forming a protective outline with a single circular beacon in the center. It communicates coverage, scrutiny, and response without relying on text.

### Signature Brand Color

**Signal Lime — #B7F960** is the unmistakable verification and live-telemetry mark of the product.
